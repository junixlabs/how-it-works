A Claude Code plugin

How It Works

Tutorials that can't go stale. Write one storyboard. It clicks through your real product and delivers a guide, GIFs, and narrated videos, checked before they ship.

34 seconds, sound on.Built from footage, narration, and diagrams that How It Works produced. No timeline editor.

Install in Claude Code

Add the marketplace, install the plugin, then run setup once. Setup adds Chromium and the Kokoro voice, which is about 1 GB and cached in ~/.cache/how-it-works.

Claude Code
/plugin marketplace add junixlabs/how-it-works
/plugin install how-it-works@how-it-works
/how-it-works:setup
Then ask
Use How It Works to make a tutorial for
https://demo.playwright.dev/todomvc: add two
tasks, complete one, then filter to the
completed list. Guide with GIFs, plus a
narrated video, wide and vertical.
